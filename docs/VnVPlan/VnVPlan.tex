\section{General Information}

\subsection{Summary}

This document contains the verification and validation plan for CEWS System, a program for calculating the CEWS measurement for a dataset as shown in \cite{zighed_statistical_2005}.
CEWS System takes a set of data points $D$ and a list of class labels $C$ as inputs and computes the Normalized Multiclass Cut Edge Weight Measurement $J_N$.

\subsection{Objectives}

The objective of this document is to build confidence in the software’s correctness.
This document provides the test plan used to verify and validate the final product.
Therefore, it should aim to encompass all validation and verification components required for testing.

\subsection{Relevant Documentation}

Relevant documentation includes the system requirements specification found here: \href{https://github.com/LesleyWheat/CAS741_CEWS/tree/main/docs/SRS}{GitHub Link}.

\subsubsection{Area of Testing 3: FR2}
This area of testing addresses the graph generation of the program and output validation of the program.
Functional Requirement 2 states: CEWS System will preform the calculation.

\begin{enumerate}

\item{T\refstepcounter{testnum}\thetestnum \textbf{\label{T:} 
 - Graph Module and relativeNeighborhoodGraph Test on UCI Dataset Tests}}

Control: Automated
					
Initial State: Pending Input
					
Input: UCI Machine Learning Repository datasets: Breast Cancer, Haberman, Glass Identitification, Image seg, Ionosphere, Iris (Bezdek), Iris, Wine recognition and Yeast.
					
Output: The Graph Module connection matrix.

Test Case Derivation: FR2

Modules: Graph Module
					
How test will be performed: PyTest
\begin{enumerate}
\item Format a dataset
\item Input the reformatted dataset to the system
\item Record the output of the graph module.
\item Check the output matches the output of 
relativeNeighborhoodGraph Python library \cite{pythonRNG}.

\end{enumerate}

\item{T\refstepcounter{testnum}\thetestnum \textbf{\label{T:out big} 
 - Graph Generation: Square}}

Control: Automated
					
Initial State: Pending Output
					
Input: A dataset of points that form a square.
					
Output: A connection matrix that has edges only on the edge of the square.

Test Case Derivation: FR2

Modules: Graph Module

How test will be performed: PyTest

\item{T\refstepcounter{testnum}\thetestnum \textbf{\label{T:out big} 
 - Graph Generation: Line}}

Control: Automated
					
Initial State: Pending Output
					
Input: A dataset of points that form a line.
					
Output: A connection matrix that has edges only connecting the closest points.

Test Case Derivation: FR2

Modules: Graph Module

How test will be performed: PyTest

\item{T\refstepcounter{testnum}\thetestnum \textbf{\label{T:out big} 
 - Output Out of Bounds: Too Large}}

Control: Automated
					
Initial State: Pending Output
					
Input: $J_N > J_{\max}$
					
Output: Generate ValueError.

Test Case Derivation: FR2

Modules: Output Module

How test will be performed: PyTest

\item{T\refstepcounter{testnum}\thetestnum \textbf{\label{T:out small} 
 - Output out of Bounds: Too Small}}

Control: Automated
					
Initial State: Pending Output
					
Input: $J_N < J_{\min}$
					
Output: Generate ValueError.

Test Case Derivation: FR2

Modules: Output Module

How test will be performed: PyTest

\end{enumerate}

\subsubsection{Area of Testing 4: FR3}
This area of testing addresses the reproducibility of the program.
Functional Requirement 3 states: The CEWS System will generate the exact same output for the exact same dataset.

\begin{enumerate}

\item{T\refstepcounter{testnum}\thetestnum \textbf{\label{T:repro} 
 - Reproducibility on UCI Dataset Tests}}

Control: Automated
					
Initial State: Pending Input
					
Input: UCI Machine Learning Repository datasets: Breast Cancer, Haberman, Glass Identitification, Image seg, Ionosphere, Iris (Bezdek), Iris, Wine recognition and Yeast.
					
Output: Normalized CEWS Measurement $J_N$.

Test Case Derivation: FR3

Modules: Control Module, Input Module, Calculation Module, Graph Module, Output Module
					
How test will be performed: PyTest
\begin{enumerate}
\item Format a dataset
\item Input the reformatted dataset to the system
\item Record the value $J_N$
\item Repeat SHUFFLE\_TIMES: Shuffle the input dataset and check the calculated value of $J_N$ against the first value $J_N$.
\end{enumerate}

\end{enumerate}
